# Automação de E-mail com IA

Aplicação em Python para análise e triagem de e-mails utilizando um modelo de linguagem executado localmente.

O sistema utiliza **Qwen3 através do Ollama** para analisar mensagens, classificá-las, definir sua prioridade, gerar um resumo, identificar quando é necessária intervenção humana e sugerir uma resposta.

## Funcionalidades

- Classificar e-mails por categoria
- Definir prioridade da mensagem
- Gerar um resumo do conteúdo
- Identificar necessidade de atendimento humano
- Gerar uma resposta sugerida
- Executar o modelo de IA localmente
- Retornar respostas estruturadas
- Validar a saída da IA com Pydantic
